# 泰国旅居手册 · Thailand Long-Stay Handbook

一份面向**长期居住**（而不是旅游）的泰国实用手册。覆盖签证体系、办理流程、落地手续、城市选择、生活成本、医疗、税务与避坑。

> 政策与价格核对日期：**2026 年 10 月 5 日**
> 汇率基准：1 元人民币 ≈ 5.0 泰铢
> 适用身份：中国护照 · 单人

## 交互功能

- **签证选型问答器**：5 个问题，输出主推方案 + 备选方案 + 风险提醒
- **生活成本计算器**：城市 × 档位 × 房型 × 代步 × 保险，实时算出月度明细与年度总额
- **时间线清单**：勾选状态保存在浏览器本地（localStorage），不上传

所有交互均在本地浏览器运行，无后端、无外部依赖、无埋点。
